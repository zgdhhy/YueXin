# 后台能配置什么

登录后进入 `/admin`。术语见 [GLOSSARY.md](../GLOSSARY.md)。

- **定时计划**：论文精选（每周哪几天、几点、推荐几篇）与趋势月报（每月几号、几点），修改后 30 秒内生效。
- **提示词**：「提示词助手」听你描述产出哪里不满意，参考近期产出和历史偏好给出修改后的写作要求（按行显示差异），一键保存为新版本。每个环节的写作要求按版本保存，启用前可用一篇已有论文或某个月份「试写」，与当前产出并排对比后再启用；运行开始时锁定所用版本。重新解读会保留旧修订，可在解读预览里对比并切换生效的一版。
- **选题与方向**：每个关注方向显示一句话描述和近期命中的论文；「方向助手」用大白话对话生成方向草稿，先看近期会命中哪些论文再保存。参数页只保留论文来源与新旧论文比例，其余放在「高级」。
- **模型**：可以添加多个服务商与模型（Anthropic、OpenAI 兼容、Responses、Gemini、ChatGPT 订阅）。选题精选、论文解读、讲解脚本、动画代码、趋势月报和对话（助手与追问）六个环节可以分别覆盖全局默认与备用模型。服务商目录来自 CC Switch，见 [CC Switch 适配说明](third-party/cc-switch.md)。
- **视频**：风格库内置深色科技、学术幻灯片、数学动画、科技快讯、白板手绘，可新建、复制、停用，每个风格可生成约 20 秒样片。也可「从参考视频生成」：上传不超过 10 分钟、200MB 的视频，worker 抽关键帧交给能看图的对话模型提炼风格，生成停用中的新风格和样片，确认后启用，原视频分析完即删除。生成设置里选择自动挑风格或固定风格、旁白（OpenAI 兼容服务商的语音合成）、背景音乐与曲库。解读详情的「视频」页签可编辑讲解脚本、让 AI 改单个镜头，再「重新生成视频」只重写改过的镜头。白板手绘的手写字体需要渲染机器装有霞鹜文楷等字体，否则退回普通字体。
- **通知**：飞书、企业微信、钉钉群机器人（支持加签）、邮件（可直接填写 SMTP）；每个渠道选择接收哪些事件，可保存并发送测试消息。
- **内容管理**：解读按标签、月份筛选并分页，可批量重新解读、重做视频或删除（删除后该论文不再推荐）；月报可查看与重做。

前台阅读站（论文库、视频、研究方向、月报、阅读工作台）的视觉与交互规范见 [apps/web/DESIGN.md](../apps/web/DESIGN.md)。
