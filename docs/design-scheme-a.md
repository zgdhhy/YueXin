# 方案 A：安静的阅读室

## 设计约定

- 背景 #F5F7F9、阅读面 #FFFFFF、正文 #243447、辅助文字 #617184、强调 #147D92、分隔 #DFE6EB。
- 界面使用 Microsoft YaHei / PingFang SC；论文标题与长文使用 Source Han Serif SC / SimSun。字号采用 13 / 15 / 17 / 22 / 28 / 40，正文行高 1.95。
- 首页宽度 960px，精选文字宽度 740px；详情使用 184px 左目录 + 720px 正文，间距 48px；后台导航 216px，设置表单最大 880px。
- 标题、摘要、正文左对齐；一个视图只有一个主要操作。列表直接分隔，不重复套卡片。

```text
前台：首页推荐 → 往期阅读 → 方向与月报
详情：左目录 | 标题 → 阅读摘要 → 可展开视频 → 正文 → 延伸阅读
后台：侧导航 | 待处理 → 当前任务 → 近期记录 → 累计摘要
设置：侧导航 | 设置路径 → 分组表单 → 明确保存
```

## 取舍

- 不放首屏标签侧栏和无效封面占位，避免辅助信息与论文争夺注意力。保留真实论文标题和原始解读，不补造研究结论。
- 手机端单列阅读：目录折叠，设置导航收起；表格只在必要时局部横向滚动。640px 扩展首页下方分栏，1024px 启用阅读目录和后台固定侧栏。
- 尊重减少动态效果设置，提供跳转正文、键盘焦点与原生表单行为。弹窗复用原生 dialog 管理焦点，危险操作使用 alertdialog。
