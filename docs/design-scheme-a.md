# 阅读站设计：清晰的研究阅读空间

## 视觉与结构

- 统一覆盖首页、论文库、视频、研究方向及详情、月报及详情、研究归档、论文解读。登录入口沿用同一品牌。
- 暖灰画布 #F7F7F5、白色内容面，深墨 #202D3B、正文 #475462、次要文字 #626E7A、炭蓝操作 #304559。统一规范见 `apps/web/DESIGN.md`。
- 首页独立采用宣纸暖白、墨色与铜色（变量集中在 `home.css` 顶部），大字分栏、叠层论文预览；月报与方向在下方展开。浮动胶囊导航、小屏展开菜单；图示／视频切换与阅读提要保留。其他合集和正文保持浅色，具体覆盖见 `apps/web/DESIGN.md` 的 Homepage 章节。
- 论文库按方向和发布时间浏览，不再提供搜索、收藏、阅读状态和不感兴趣入口；保留旧数据，旧标记不再隐藏前台解读。
- 展示与文章主标题使用自托管 Reading Display（Noto Serif SC 子集，600 字重）；正文与操作使用 Reading Sans（Noto Sans SC 子集，400–600 字重），保留中文系统回退。字体文件与 OFL 许可位于 `apps/web/public/fonts/`。
- 桌面正文最大 760px，18px 无衬线，行高 1.95，左对齐。段落、二三级标题与留白形成连续文章；公式和表格只在局部滚动。
- 解读开篇展示“为什么值得读”和视频播放器，不要求展开论文资料。论文信息收纳来源、作者、机构、研究方向及同期值得关注的原论文。
- 标识为深色圆角书页叠层；阅读站操作图标采用项目内统一 SVG，默认线宽 1.6px。

## 阅读操作面板

- 论文与月报共用阅读工作台，隐藏阅读页顶部浮动导航，保留文章标题。目录紧贴文章左侧常驻，无目录按钮；宽阅读区正文自身居中。助手、笔记与论文／月报信息共用面板，按钮保持位置并悬浮于内容上层，仅输入框避让，不预留整列按钮空间。另有返回顶部按钮。默认右停靠 420px，支持左停靠、浮动、全屏。停靠分隔线可拖拽调宽（360–720px，正文区至少 520px）；浮动窗口可拖标题栏移动及八方向缩放（默认 480×600px，最小 360×360px），限制在视口内。停靠允许正文重排，同时保持可见正文块位置；点击正文不关闭面板。
- 面板顶部仅提供当前视图名称、位置菜单和收起按钮；追问内部仅保留历史、新对话和当前会话。历史会话与聊天共用相同尺寸的窗口，会话以带边框和间距的独立卡片展示，长列表内部滚动；重命名与删除直接归属各行，删除行内确认，保留独立会话与草稿；消息列表内部滚动。输入框自动增高，发送按钮内嵌，焦点只显示一层边框。关闭窗口后请求继续、结果保留。
- 笔记通过单一范围选择器在整篇与章节之间切换，正文标题的批注按钮直接打开章节编辑器，不再撑开正文。未匹配当前标题的旧批注仍出现在章节选择中，标为“其他章节批注”。
- Escape 优先关闭窗口菜单或退出会话内部状态；全屏时先恢复原模式，普通面板再收起并将焦点还给入口。关闭窗口不清空未保存草稿。浏览器仅记住停靠宽度与浮窗尺寸，不保存模式或坐标，每次打开默认右侧停靠，进入解读时先收起；会话删除继续行内确认。

面板主体从右下角入口以 360ms 弹性展开，以 260ms 缩回；悬浮按钮不参与缩放，减少动态效果时直接切换。笔记直接编辑已渲染的 Markdown，提供可编辑源码入口，无分栏预览；论文与每期月报的笔记和会话互相隔离。

## 统一适配

- 900px 起默认展开文章左侧目录，无单独目录入口；空间不足以容纳正文和操作面板时临时浮动。月报与论文使用同一布局和功能。
- 900px 以下缩减页面间距；640px 以下首页、论文与视频目录采用单列。
- 手机正文 17px，浮窗适应可用宽高，始终保持独立覆盖模式。移动端不再将正文切成半屏滚动区域。
- 尊重减少动态效果，保留可见键盘焦点、跳转正文与原生视频操作。
