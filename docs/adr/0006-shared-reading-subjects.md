# 论文与月报共用阅读对象和工作台

论文解读与趋势月报使用同一阅读工作台、笔记及多会话流程。为保留已有论文笔记和对话，论文的阅读对象标识仍是原论文 ID，月报使用保留命名空间 `report:YYYY-MM`；已有 `notes.paper_id` 和 `conversations.subject` 保存该标识，阅读对话沿用历史 `paper` 类型。读写必须先验证对应解读存在，且会话归属必须按完整阅读对象标识校验。

相比新增月报专用表，这一选择让两个入口保持相同的交互与数据行为，无需搬迁旧笔记；代价是存储中部分历史字段名比当前含义狭窄。`getReadingDocument` 负责解释命名空间，月报助手只使用对应月报内容，不读取论文原文缓存。月报重做沿用同一月份，因此原有笔记和会话仍保留。
