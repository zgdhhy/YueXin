# 讲解视频改为由大模型逐镜头编写动画代码

取代 [ADR 0001](0001-storyboard-driven-video.md)。讲解视频的目的是让人更生动地理解论文的知识点和闪光点。固定场景模板只能往格子里填字，画面也只能照着解读文章排，所以改为：大模型先从论文原文写出可编辑的**讲解脚本**（镜头 = 文案 + 画面说明），再由「动画代码」环节为**每个镜头**单独写一段 Remotion（React）代码。字幕、旁白、音乐、进度条和镜头拼接仍然由固定框架负责。

我们接受更高的失败率，换取更强的表现力：

- 代码按镜头拆分，所以改一个镜头只重写这一段，一段出错也只影响这一个镜头。
- 某个镜头无法渲染时，不重试，直接退化为只显示「标题 + 文案」的简单画面，视频照常产出，并在后台标出这个镜头。
- 引擎先只用 Remotion，因为它和现有技术栈一致，也能借用官方 Claude skills 里的约束。Manim 留到以后再加。

## Consequences

- 论文内容是不可信输入，可能借提示注入让模型写出恶意代码。因此生成的代码在执行前要通过导入白名单的静态检查。渲染时只把本镜头用到的素材提供给浏览器，不再把整个 `DATA_DIR` 暴露出去（里面有 `app.db` 和凭据）。
- 每次渲染不再只打包一次固定组件，需要在运行时编译镜头代码。
