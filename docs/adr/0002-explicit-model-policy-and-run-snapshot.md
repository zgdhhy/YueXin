# 显式默认模型、环节覆盖与运行配置快照

模型配置采用一个明确的全局默认模型和可选备用，四个环节按需覆盖。旧配置仅供升级参考，用户确认之前不消费新的模型运行；不再以数据库排序或任意启用项替代失效模型，避免未经用户选择的质量和费用变化。

Worker 在认领 queued 运行的同一事务中固定模型、接口地址和调用策略，后续修改仅影响新运行。快照不复制凭据，请求时仍从服务端读取轮换后的 Key 或刷新 OAuth；被运行引用的模型与服务商在结束前不能删除。这样以额外的配置解析与快照记录换取同次运行的稳定性，同时允许必要的凭据轮换。

模型能力、调用策略与内容要求分别处理。输出预算默认自动解析，只有确有需要才在高级设置覆盖，避免用一个 token 数字同时表达能力上限和文章长度。
