# 解读采用自由章节，保留生成契约与历史内容

修订 [ADR 0004](0004-versioned-writing-requirements.md) 中固定八段的约定，继续保留可版本化写作要求与程序控制的输出格式边界。固定八段容易导致重复总结、硬凑趋势和术语栏目，增加阅读负担；解析器实际只依赖元信息与 Markdown 分节，因此章节名称、数量和顺序由论文的论证决定，仍须覆盖问题、贡献、机制、证据与局限。

章节标题仍是旧批注的关联依据。保留精确匹配，未匹配的批注在笔记面板显示原标题，不自动猜测迁移。旧文章不批量重写，新规范先作为待选版本试写；采用一篇试写与启用未来写作要求分别确认。采用精确复用已完成试写，保留修订、视频和读者记录。
