# 路线图

2026-10-27 讨论定下的前台、后台演进方向。术语见 [GLOSSARY.md](../GLOSSARY.md)，关键取舍见 `docs/adr/`。按「先基础、后 AI」推进，每个阶段开工前单独细化。

## 定位

- 前台是**个人知识库**，不是公开内容站：围绕「探索研究 → 理解论文 → 追问 → 留下笔记」组织。
- 后台导航分两组：
  - 工作区：概览、内容（解读 / 月报）
  - 配置：选题与方向、提示词、视频（风格库 / 音乐与旁白）、模型、定时计划、通知
- 前台导航：首页、论文库、视频、研究方向、趋势月报；首页介绍网站与阅读方式，论文库按研究方向和发布时间浏览。

## 阶段

### 1. 定时计划 + 通知重做（已完成）

- **定时计划**
  - 页面只有两张卡片：论文精选（星期几 + 时间 + 推荐篇数）和趋势月报（每月几号 + 时间），不再出现 cron。
  - 错过的时间不补跑。
- **通知**
  - 新增渠道用「先选类型、再填表」的向导，每种类型只显示自己需要的字段。
  - 每个渠道单独勾选接收哪些事件：新解读、新月报、运行失败。
  - 手动运行也推送。
  - SMTP 可以在邮件渠道里填写，`.env` 只作为回退。
  - 只保留飞书、企业微信、钉钉、邮件，不接 QQ 和个人微信。

### 2. 内容管理 + 前台知识库（已完成）

- **后台**
  - 去掉上线 / 下线，不提供手动编辑解读的功能。
  - 删除解读会同时删除文件，并把该论文记为不再推荐，相当于一次「不感兴趣」。
  - 支持批量操作（重新解读、重做视频、删除）。
  - 新增月报列表和重做。
  - 支持按标签、日期筛选，列表分页。
- **前台**
  - 全站统一蓝灰主题、排版与图标，首页介绍阅读方式并展示本期研究。
  - 论文库取消搜索、收藏、已读和不感兴趣；停止记录阅读进度，历史标记不再控制论文可见性。
  - 解读默认显示入选理由和视频。追问、笔记、资料和目录共用可左／右停靠、浮动及全屏的操作面板；支持拖拽调宽与浮窗八方向缩放。默认左侧目录，阅读页取消顶部浮动导航；助手和笔记控件嵌入面板并从右下角弹性打开，笔记支持 Markdown 实时预览。月报共用工作台，停靠重排时保持阅读内容，草稿与进行中请求保留。
- **笔记**：整篇笔记，以及按章节标题精确关联的段落批注；重新解读后仍按标题关联，未匹配的旧批注在笔记面板集中保留。
- **视频页**：独立页面，网格排列，点开在弹层播放；论文库去掉「只看有视频」。

### 3. 提示词版本（ADR 0004，已完成；选题精选暂不支持试写）

- 新增「提示词」页，按环节分页签：选题精选、论文解读、讲解脚本、动画代码、趋势月报。
- 只有写作要求可以修改，修改会产生版本；元信息和 Markdown 分节契约固定，解读章节可根据论文自由组织，语义覆盖问题、贡献、机制、证据和局限。解读内置规范升级先成为待选版本，试写后主动启用。
- 运行开始时锁定所用版本，每篇产出都记录它来自哪个版本。
- 启用新版本前可以先「试写」，与当前版本并排对比。
- 重新解读会产生新的解读修订，旧修订保留，可以对比并选择哪一版生效；月报重做则直接覆盖。

### 4. 对话环节、方向助手、论文追问（已完成）

- 新增「对话」环节，助手、论文追问、参考视频分析都用它。
- **选题与方向**
  - 主题卡片显示中文名、一句话描述（同时交给精选环节参考）和近期命中的论文示例。
  - arXiv 分类、关键词、权重收进「高级」，由助手生成。
- **方向助手**：用户用大白话描述兴趣，助手追问澄清后生成主题草稿，再用近期论文试选一次，用户确认后保存。
- **反馈**
  - 已有的收藏、不感兴趣记录与后台删除作为历史偏好样例交给精选环节；前台不再收集新的阅读标记。
  - 助手可以根据反馈建议调整主题，但不会自动修改。
- **选题参数**：主界面只留来源开关和「新论文 ↔ 近期重要论文」比例，其余放进「高级」并改用白话说明。
- **论文追问**：依据原文（`DATA_DIR/papers/<id>/content.json`）和解读回答；对话历史保留，回答可以一键存为笔记。

### 5. 视频重构（ADR 0003，已完成；旁白改用服务商 TTS）

**生成流程**
1. 论文原文和原图（解读只作参考）交给「讲解脚本」环节，产出镜头列表。
2. 「动画代码」环节逐个镜头写 Remotion 代码。
3. 由固定框架把镜头拼起来，并加上字幕、音乐、旁白。

**编辑**
- 定时运行一路自动出片，用户事后可以修改脚本。
- 编辑入口在解读详情的「视频」页签：
  - 改文案和画面说明，增删镜头、调整顺序。
  - 每个镜头可以「让 AI 改」。
  - 代码只读。
- 重新生成时只重写改过的镜头，并覆盖旧视频。
- 镜头代码出错时不重试，直接退化为简单画面，并在后台标出。

**风格库**
- 内置预设，借鉴 remotion-dev/skills、claude-code-video-toolkit、HyperFrames 的配色、字体和禁忌清单，以及 Paper2Video 的学术幻灯片风格。
- 每个风格附一段样片。
- 选择方式有三种：固定一个风格；写脚本时自动挑选并说明理由；重做时临时指定。

**旁白**
- 视频页有一个全局开关，音色和语速由风格决定。
- 先接 Edge TTS，以后可以扩展到付费服务商。

**安全**
- 生成的代码要做导入白名单检查。
- 渲染时只提供该镜头用到的素材。

**本期不做**：竖屏。

### 6. 提示词助手 + 参考视频分析（已完成）

- **提示词助手**：参考当前写作要求、近期产出和反馈，输出差异草稿，可以直接试写。
- **参考视频分析**
  - 用户上传视频文件（有大小和时长上限）。
  - 系统抽取关键帧和剪辑节奏，交给能看图的模型生成风格草稿，再渲染样片。
  - 大模型适配层需要先支持图片输入。
